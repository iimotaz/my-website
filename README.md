# موقع محفظة Motaz — محرر فيديو

نسخة مطابقة لمشروعك على Lovable، مبنية كموقع ثابت سهل التعديل
مع ميزات إضافية: تبديل عربي/إنجليزي، وضع داكن/فاتح، ألوان وخطوط قابلة للتغيير.

## 📁 هيكل المشروع

```
my-website/
├── edit.html      # ⭐ لوحة التعديل - افتحها لتعديل موقعك بدون أي أكواد
├── editor.js      # وظائف لوحة التعديل
├── config.js      # ملف الإعدادات (تُنتجه اللوحة تلقائياً - لا تعدّله يدوياً)
├── index.html     # هيكل الصفحة (لا حاجة لتعديله غالباً)
├── styles.css     # التنسيقات
├── script.js      # الوظائف
├── assets/        # الصور: البروفايل وصور الفيديوهات المصغرة
└── vercel.json    # إعدادات Vercel
```

## 🎛️ لوحة التعديل (الأسهل)

> ⚠️ **لوحة التعديل للاستخدام المحلي فقط** — افتحها من جهازك ولا ترفع `edit.html` و`editor.js` إلى الموقع المنشور، ليبقى موقعك نظيفًا وآمنًا.

افتح الملف **`edit.html`** في متصفحك (النقر المزدوج عليه)، وستجد أمامك لوحة
عربية كاملة تسمح لك:

- تغيير اسمك وصورتك الشخصية ونبذتك (الصور تُرفع من جهازك مباشرة)
- تغيير لون الموقع وخطه ووضعه (داكن/فاتح)
- إضافة أو حذف **الفيديوهات الطويلة والقصيرة** مع صورها المصغرة
- إضافة أو حذف **العملاء** وأقسام الخدمات وخطوات العمل
- تعديل روابط التواصل والواتساب والبريد

بعد انتهائك اضغط زر **"تحميل config.js"** واستبدل الملف القديم به — انتهى.
وإن كان موقعك منشوراً ارفع الملف الجديد إلى GitHub وسيتحدث الموقع تلقائياً.

## ✏️ الطريقة اليدوية (لمن يفضل الكود)

افتح ملف **`config.js`** — كل المحتوى موجود فيه مع شرح عربي بجانب كل خيار:

| ماذا تريد؟ | أين في config.js؟ |
|---|---|
| الاسم (Motaz) | `name` |
| صورة البروفايل | `avatar` — ضع صورتك في `assets/` واكتب المسار هنا |
| الشارة أسفل اسمك | `badge` ("Video Editor") |
| جملة الترحيب والوصف | `heroGreeting` و `heroDesc` |
| الفيديوهات الطويلة | `longForm` (3 فيديوهات: العنوان، الوصف، الوسوم، المدة، الصورة، رابط التشغيل) |
| الفيديوهات القصيرة | `shortForm` (4 فيديوهات عمودية) |
| الخدمات "What I Do" | `services` (الأيقونة، العنوان، الوصف) |
| خطوات العمل | `process` (01-04) |
| رابط الفيديو عند النقر | `embedUrl` (ضع رابط يوتيوب `https://www.youtube.com/embed/...`) |
| تغيير اللغة الافتراضية | `language: "en"` أو `"ar"` |
| تغيير الخط | `font: "Thmanyah_Serif_Text"` → `"Thmanyah_Sans"` أو `"Cairo"`... |
| تغيير اللون الرئيسي | `accent: "green"` → `"blue"`, `"purple"`, `"orange"`, `"teal"`, `"pink"`, `"red"` |
| الوضع الافتراضي | `theme: "dark"` → `"light"` أو `"system"` |
| اللمسة الخاصة | `tagline` (تظهر في الأسفل) |
| رقم واتساب | `contact.whatsapp` (بصيغة دولية بدون +) |
| بريدك | `contact.email` |
| طريقة استقبال الرسائل | `contact.receiveMethod`: `"whatsapp"` / `"email"` |
| وسائل التواصل | `socials` (اترك `url` فارغاً لإخفاء الأيقونة) |

## 🌍 التبديل بين اللغات والثيم

- زر **EN / ع** في الشريط العلوي يبدّل اللغة فوراً (عربي/إنجليزي).
- زر **الشمس/القمر** يبدّل الوضع الداكن/الفاتح.
- الموقع يتذكر اختيار الزائر تلقائياً.

## ▶️ فتح الفيديوهات

انقر على أي فيديو فتفتح نافذة تشغيل تلقائياً. حالياً روابط الفيديو عينات
يوتيوب — استبدلها بروابط أعمالك في `config.js`.

## 🚀 النشر على Vercel

1. سجّل في https://vercel.com (يفضّل بحساب GitHub).
2. ارفع ملفات المجلد إلى مستودع جديد في GitHub:
   - github.com → **+** → **New repository** → الاسم `my-website` → Create
   - اضغط **uploading an existing file** واسحب محتويات مجلد `my-website` كاملة.
3. في Vercel: **Add New → Project** → اختر `my-website` → **Deploy**.

تحصل على رابط مجاني مثل: `https://my-website.vercel.app`
أي تعديل ترفعه إلى GitHub سيعيد Vercel نشره تلقائياً خلال دقيقة.
